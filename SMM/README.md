# Minecraft Server Manager

![Minecraft Server Manager](https://img.shields.io/badge/Version-1.0.0-brightgreen)
![Python](https://img.shields.io/badge/Python-3.6%2B-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)

Полнофункциональный менеджер серверов Minecraft с графическим интерфейсом, написанный на Python.

## 🚀 Возможности

- **Автоматическая загрузка ядер** - Поддержка Purpur, Paper, Fabric, Forge и Vanilla
- **Управление несколькими серверами** - Создание и переключение между проектами
- **Встроенная консоль** - Просмотр логов и отправка команд в реальном времени
- **Файловый менеджер** - Удобное управление файлами сервера
- **Управление плагинами** - Загрузка и удаление плагинов через интерфейс
- **Настройка параметров** - Редактирование server.properties и других конфигураций
- **Есть программа для Windows!** - перетащите .exe файл в любую папку и запустите программа сама всё сделает

## 📦 Установка

### Требования
- Python 3.6 или выше
- Java 8 или выше (для запуска серверов Minecraft)
